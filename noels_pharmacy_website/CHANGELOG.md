# Changelog

## 19.0.1.2.0

- Reworked the homepage into a more cohesive, photo-led pharmacy campaign.
- Replaced the text-only service cards with an editorial care mosaic using real photography.
- Added graceful homepage layouts for sparse Odoo catalogues and category lists.
- Removed technical Odoo wording from customer-facing homepage copy.
- Compacted and refined the desktop header and elevated the trust strip into a floating panel.
- Set the default website identity to Noel's Pharmacy &amp; Wellness Center Ltd.

## 19.0.1.1.0

- Restored Odoo's full Settings screen by converting the Noel's configuration form into an inherited Website settings block.
- Added a full-width, three-slide photographic homepage banner with accessible controls and optional autoplay.
- Added responsive desktop, tablet and mobile banner compositions with stronger mobile overlays and full-width actions.
- Added locally bundled, optimized WebP photography for the homepage wellness and local-care sections.
- Added photography source and license references in `IMAGE_CREDITS.md`.

- Added full stylesheet compilation to the release validation workflow.
